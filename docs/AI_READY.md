# Save tokens. Save energy. Use AI cleverly.

Une IA travaille mieux quand elle reçoit le bon extrait, dans le bon format, plutôt qu'un document entier difficile à lire. Convertir localement un PDF, une image ou un tableau en TXT, Markdown, JSON ou CSV peut éviter de refaire l'extraction à chaque utilisation.

**Save tokens** : un texte utile ou un tableau ciblé occupe souvent moins de contexte qu'un document brut. **Save energy** : réutiliser un résultat déjà préparé évite des traitements répétés. **Use AI cleverly** : gardez la maîtrise de vos documents et transmettez seulement ce dont l'outil choisi a besoin.

Ce sont des objectifs de conception, pas une promesse de réduction mesurée pour chaque fichier. L'application actuelle est un convertisseur local ; elle n'inclut pas de moteur RAG, de recherche sémantique ni d'IA distante. Voir la [feuille de route](ROADMAP.md) pour les étapes envisagées.
